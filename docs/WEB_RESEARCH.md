# Web search and deep research

Set Laravel `SEARXNG_SEARCH_URL` to your own SearXNG `/search` URL with JSON format enabled, then refresh Laravel config and restart workers. The search buttons appear when the backend advertises this capability. Search queries leave the app for that search service and its configured search engines. No paid search API or public SearXNG fallback is bundled.

In the chat composer, choose **Web search** for one search and a concise answer from snippets, or **Deep research** for a report built from three complementary queries. Choose any time, past day, week, month or year. Time filtering depends on the engines enabled in SearXNG and is not proof of a page's publication date.

Deep research collects at most eight unique URLs, at most two per exact hostname (www aliases are grouped), and attempts to read at most six public HTML/text pages. Query expansion is a fixed topic/documentation/limitations strategy, not an autonomous planning loop. Search requests time out after eight seconds, page requests after six seconds, and new collection work stops after a 45-second budget. A request already in flight can finish beyond that budget. Each page contributes at most 8,000 characters to the report context. URLs lose tracking parameters/fragments; duplicates are removed. Readable pages, unavailable pages and snippets are labeled separately. Partial search outages can still produce a report from available evidence; no evidence produces an explicit error.

NVIDIA reports follow the existing direct **Next.js server → NVIDIA** inference path. Laravel collects sources and prepares context; it stores the user question, assistant answer/status and source summaries. It does not call NVIDIA. Full extracted page text is sent as model context and is not retained in message/source records. Existing local models support the same interactive research mode. Temporary chats retain their existing no-message-storage behavior.

The model is instructed to cite supplied URLs next to supported claims, distinguish conflicting evidence and explain gaps. These prompts do not guarantee factual accuracy or prevent every prompt-injection attempt. Source cards show actual retrieval status independently of generated claims. Chat reports can be downloaded as Markdown with a source-evidence appendix. Search snippets are never presented as full-page verification. The page reader retains public-IP validation, pinned DNS, bounded downloads, content-type restrictions and rejection of redirects/private networks. JavaScript-rendered sites, login pages, PDFs and blocked sites may remain unreadable.

The Research workspace also uses the same improved collection pipeline for persistent background runs, with per-search/read progress, cancellation between requests and Markdown report download. Those queued runs still require an enabled local inference model plus the scheduler and `tasks` queue worker. For NVIDIA, use Deep research in the chat composer. Interactive collection shows a preparation indicator; it does not stream per-source progress before generation starts. Stopping during collection may take until preparation finishes; the provider request is then skipped/cancelled and finalization is attempted.

Configure the Next.js host request duration and ingress/SSE timeouts for a full research turn (up to roughly 200 seconds including collection, generation and save retries). Laravel/PHP must allow the preparation request to complete; a 30-second PHP execution limit can interrupt collection. The app proxy allows 220 seconds for local streaming, the NVIDIA bridge allows 80 seconds for preparation and 110 seconds for generation. Worker research retains its 240-second task timeout. There is no live search/NVIDIA validation bundled; deployment needs working SearXNG and NVIDIA credentials where applicable.

Official search API: https://docs.searxng.org/dev/search_api.html
